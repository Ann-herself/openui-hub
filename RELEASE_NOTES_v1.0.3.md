# OpenUI Hub v1.0.3 — Windows Release

OpenUI Hub v1.0.3 is a packaged Windows release for managing self-hosted Syncthing files, folders, and devices through a clean local interface.

## Downloads

- `OpenUI-Hub-Setup-v1.0.3.exe` — recommended Windows installer
- `OpenUI-Hub-Portable-v1.0.3.zip` — portable Windows package
- `SHA256SUMS.txt` — SHA-256 checksums

## Included

- File and folder browsing
- Upload and download
- File and folder creation, rename, and deletion
- Syncthing folder creation and management
- Remote device management
- Local Device ID display and copy action
- Activity and folder-error overview
- Application and Syncthing settings overview
- Packaged FastAPI backend and React frontend
- Windows launcher and bundled Syncthing runtime
- Standard installer and portable distribution

## Installation

1. Download `OpenUI-Hub-Setup-v1.0.3.exe`.
2. Close any older OpenUI Hub or Syncthing process started by a previous version.
3. Run the installer.
4. Launch OpenUI Hub from the Windows Start Menu.

The application opens locally in the default browser.

## Windows Notice

The installer may display a Windows publisher warning until the executable is code-signed. Verify the downloaded file using `SHA256SUMS.txt` when required.
